# UX 리뷰랩

화면, Figma 링크, 이미지 또는 프로토타입 영상을 AI와 함께 빠르게 점검하기 위한 UX 리뷰 가이드예요.

UX 리뷰랩은 세 가지 기능을 필요한 만큼 선택해서 사용할 수 있어요.

- 기본 실행: 빠른 UX 점검 + AI 리뷰팀
- 선택 실행: AI 예상 주목도 맵
- 사용자가 기능이나 번호를 지정하면 선택한 기능만 실행

## 스킬로 설치하기

설치하면 다른 폴더에서도 긴 프롬프트를 복사하지 않고 사용할 수 있어요. 같은 스킬 패키지를 Codex와 Claude Code에서 함께 사용할 수 있어요.

### Codex

Codex에서 `$skill-installer`를 호출한 뒤 다음 GitHub 경로의 스킬을 설치해 달라고 요청해요.

```text
https://github.com/annieppss/ux-review-lab/tree/main/skills/ux-review-lab
```

설치 후에는 다음처럼 사용해요.

```text
$ux-review-lab 이 Figma 화면을 점검해줘.
검토 팀은 UX/UI 디자이너, 기획자, 개발자로 해줘.
```

### Claude Code

개인 스킬 경로에 이 저장소의 스킬 폴더를 연결하면 모든 프로젝트에서 `/ux-review-lab`으로 사용할 수 있어요.

### Codex와 Claude Code에서 함께 사용하기

한 번 내려받은 스킬을 두 도구에서 함께 연결하면 업데이트할 파일도 하나만 관리할 수 있어요.

```bash
git clone https://github.com/annieppss/ux-review-lab.git "$HOME/ux-review-lab"
mkdir -p "$HOME/.agents/skills" "$HOME/.claude/skills"
ln -s "$HOME/ux-review-lab/skills/ux-review-lab" "$HOME/.agents/skills/ux-review-lab"
ln -s "$HOME/ux-review-lab/skills/ux-review-lab" "$HOME/.claude/skills/ux-review-lab"
```

스킬이 목록에 바로 나타나지 않으면 Codex 또는 Claude Code를 다시 시작해 주세요. 이후 업데이트는 다음 명령으로 받을 수 있어요.

```bash
git -C "$HOME/ux-review-lab" pull --ff-only
```

Figma 링크 분석에는 각 도구에 Figma MCP가 별도로 연결되어 있어야 해요. 이미지 생성·편집 기능이 없는 환경에서는 AI 예상 주목도 순서를 텍스트로 제공하고 필요한 도구를 안내해요.

- [Codex 스킬 공식 문서](https://developers.openai.com/codex/skills)
- [Claude Code 스킬 공식 문서](https://code.claude.com/docs/en/skills)

## 기능 선택 예시

기능을 지정하지 않으면 1번과 2번을 기본으로 실행해요.

| 요청 | 실행 기능 |
| --- | --- |
| `UX 리뷰랩으로 점검해줘` | 1번 빠른 UX 점검 + 2번 AI 리뷰팀 |
| `빠른 UX 점검만 해줘` | 1번만 |
| `AI 리뷰팀으로만 검토해줘` | 2번만 |
| `AI 예상 주목도 맵도 사용해줘` | 기본 1·2번 + 3번 |
| `AI 예상 주목도 맵만 만들어줘` | 3번만 |
| `1번과 3번만 사용해줘` | 1번 + 3번 |

Codex에서는 `$ux-review-lab`, Claude Code에서는 `/ux-review-lab`으로 직접 호출할 수 있어요.

## 빠른 UX 점검

일반 사용자가 화면을 처음 봤을 때 무엇을 이해하고 어디에서 막힐지 빠르게 확인해요.

- 화면의 목적이 바로 이해되는가
- 가장 먼저 보이는 요소가 의도와 일치하는가
- 다음 행동을 쉽게 찾을 수 있는가
- 문구나 상태가 혼란스럽지 않은가

[빠른 UX 점검 가이드](docs/quick-ux-review.md)

## AI 리뷰팀

고정된 일반 사용성 관점에 더해 사용자가 선택한 역할의 관점으로 화면을 검토해요.

- 추천 역할: UX/UI 디자이너, 기획자, 개발자
- 역할은 자유롭게 교체 가능
- 사용자가 선택하는 역할은 최대 3개
- 마지막에는 중복 의견을 합치고 우선순위를 정리

[AI 리뷰팀 가이드](docs/ai-review-team.md)

## AI 예상 주목도 맵

화면의 크기, 대비, 색상, 위치와 정보 위계를 바탕으로 예상되는 주목 영역을 시각화해요.

- 빨강: 가장 먼저 주목할 가능성이 높은 영역
- 주황: 다음으로 주목할 가능성이 높은 영역
- 노랑: 보조적으로 인지할 가능성이 높은 영역
- ① ② ③: 예상 주목 순서

> 실제 사용자의 시선을 측정한 결과가 아니에요. 화면의 크기, 대비, 색상, 위치와 정보 위계를 바탕으로 AI가 예측한 주목도예요.

[AI 예상 주목도 가이드](docs/ai-attention-map.md)

## 지원 입력

- Figma의 선택된 프레임 또는 섹션 링크
- PNG, JPG 등의 화면 이미지
- MP4 등의 프로토타입 또는 화면 녹화
- 공개적으로 접근 가능한 웹페이지 링크

링크 접근이 제한되면 이미지 또는 영상 파일을 직접 제공해 주세요.

## 사용 방법

1. 스킬을 설치하거나 아래 프롬프트 문서를 복사해요.
2. Figma MCP를 연결하거나 분석할 파일을 준비해요.
3. 화면의 목적과 사용자의 목표를 함께 설명해요.
4. 필요한 기능을 지정해요. 지정하지 않으면 빠른 UX 점검과 AI 리뷰팀을 실행해요.
5. AI 예상 주목도가 필요할 때만 주목도 맵을 요청해요.
6. 발견된 문제는 실제 사용자 테스트에서 다시 검증해요.

전체 동작 규칙은 [UX 리뷰랩 프롬프트](prompts/ux-review-lab-prompt.md)에 정리되어 있어요.

설치하지 않고 사용하려면 저장소 링크와 프롬프트 문서를 Codex 또는 Claude Code에 전달하세요.

## 안전 및 권한 원칙

- 사용자가 제공한 원본은 현재 분석에서만 읽기 전용으로 사용해요.
- 명시적인 허락 없이 원본 Figma를 수정하지 않아요.
- 명시적인 허락 없이 캡처나 분석 이미지를 Git에 추가하지 않아요.
- 외부에 게시하거나 예시 자료로 재사용하지 않아요.
- 링크 접근에 실패하면 임의로 우회하지 않고 파일 업로드를 안내해요.

## 한계

UX 리뷰랩은 실제 사용자 조사, 접근성 테스트, 아이트래킹 또는 사용성 실험을 대체하지 않아요. 초기 디자인에서 확인할 문제 후보를 빠르게 발견하는 사전 점검 도구예요.
