# UX 리뷰랩

화면, Figma 링크, 이미지 또는 프로토타입 영상을 AI와 함께 빠르게 점검하기 위한 UX 리뷰 가이드입니다.

UX 리뷰랩은 두 가지 방식으로 사용할 수 있습니다.

## 빠른 UX 점검

일반 사용자가 화면을 처음 봤을 때 무엇을 이해하고 어디에서 막힐지 빠르게 확인합니다.

- 화면의 목적이 바로 이해되는가
- 가장 먼저 보이는 요소가 의도와 일치하는가
- 다음 행동을 쉽게 찾을 수 있는가
- 문구나 상태가 혼란스럽지 않은가

[빠른 UX 점검 가이드](docs/quick-ux-review.md)

## AI 리뷰팀

고정된 일반 사용성 관점에 더해 사용자가 선택한 역할의 관점으로 화면을 검토합니다.

- 추천 역할: UX/UI 디자이너, 기획자, 개발자
- 역할은 자유롭게 교체 가능
- 사용자가 선택하는 역할은 최대 3개
- 마지막에는 중복 의견을 합치고 우선순위를 정리

[AI 리뷰팀 가이드](docs/ai-review-team.md)

## AI 예상 주목도 맵

화면의 크기, 대비, 색상, 위치와 정보 위계를 바탕으로 예상되는 주목 영역을 시각화합니다.

- 빨강: 가장 먼저 주목할 가능성이 높은 영역
- 주황: 다음으로 주목할 가능성이 높은 영역
- 노랑: 보조적으로 인지할 가능성이 높은 영역
- ① ② ③: 예상 주목 순서

> 실제 사용자의 시선을 측정한 결과가 아닙니다. 화면의 크기, 대비, 색상, 위치와 정보 위계를 바탕으로 AI가 예측한 주목도입니다.

[AI 예상 주목도 가이드](docs/ai-attention-map.md)

## 지원 입력

- Figma의 선택된 프레임 또는 섹션 링크
- PNG, JPG 등의 화면 이미지
- MP4 등의 프로토타입 또는 화면 녹화
- 공개적으로 접근 가능한 웹페이지 링크

링크 접근이 제한되면 이미지 또는 영상 파일을 직접 제공해야 합니다.

## 사용 방법

1. Figma MCP를 연결하거나 분석할 파일을 준비합니다.
2. 화면의 목적과 사용자의 목표를 함께 설명합니다.
3. 빠른 UX 점검 또는 AI 리뷰팀을 선택합니다.
4. AI 예상 주목도가 필요하면 원본과 주목도 맵을 함께 요청합니다.
5. 발견된 문제는 실제 사용자 테스트에서 다시 검증합니다.

전체 동작 규칙은 [UX 리뷰랩 프롬프트](prompts/ux-review-lab-prompt.md)에 정리되어 있습니다.

## 안전 및 권한 원칙

- 사용자가 제공한 원본은 현재 분석에서만 읽기 전용으로 사용합니다.
- 명시적인 허락 없이 원본 Figma를 수정하지 않습니다.
- 명시적인 허락 없이 캡처나 분석 이미지를 Git에 추가하지 않습니다.
- 외부에 게시하거나 예시 자료로 재사용하지 않습니다.
- 링크 접근에 실패하면 임의로 우회하지 않고 파일 업로드를 안내합니다.

## 한계

UX 리뷰랩은 실제 사용자 조사, 접근성 테스트, 아이트래킹 또는 사용성 실험을 대체하지 않습니다. 초기 디자인에서 확인할 문제 후보를 빠르게 발견하는 사전 점검 도구입니다.
