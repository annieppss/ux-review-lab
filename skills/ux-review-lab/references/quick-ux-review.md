# 빠른 UX 점검

처음 화면을 접한 일반 사용자의 이해와 행동을 중심으로 점검한다.

## 확인할 내용

1. 화면의 목적이 바로 이해되는가?
2. 의도한 핵심 요소가 가장 먼저 보이는가?
3. 다음 행동이나 CTA를 쉽게 찾을 수 있는가?
4. 문구, 선택 상태, 오류·로딩·완료 상태가 명확한가?
5. 흐름을 막거나 되돌아가게 만드는 지점이 있는가?

## 결과 형식

```text
한 줄 결론

잘 이해되는 부분
- ...

혼란 가능성이 있는 부분
- ...

우선 수정할 항목
1. ...
2. ...
3. ...

실제 사용자 테스트에서 확인할 내용
- ...
```

실제 행동 데이터가 아니라 화면을 바탕으로 한 사전 점검임을 명시한다.
