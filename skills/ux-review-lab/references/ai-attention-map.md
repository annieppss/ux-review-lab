# AI 예상 주목도 맵

실제 아이트래킹 데이터가 아니라 화면의 크기, 대비, 색상, 위치와 정보 위계를 바탕으로 예상되는 주목 영역을 시각화한다.

## 실행 조건

이 기능은 사용자가 명시적으로 요청한 경우에만 실행한다. 원본 캡처와 이미지 편집 또는 생성 도구를 사용할 수 있는지 먼저 확인한다.

## 기본 출력

1. 원본 화면 캡처
2. AI 예상 주목도 오버레이
3. 빨강·주황·노랑 주목 영역
4. ① ② ③ 예상 주목 순서
5. 의도한 핵심 요소와 예상 주목 요소 비교
6. 위치·크기·색상·대비 개선 제안

## 처리 범위

- 화면 1개: 자동 분석
- 화면 2~3개: 모두 분석
- 화면 4개 이상: 핵심 화면 3개를 먼저 분석하고 전체 분석 선택 제공
- 영상: 시작·전환·완료 등 핵심 장면 3~5개 추출
- 긴 화면: 전체 축소본 하나보다 실제 뷰포트별 분석 우선

## 표시 기준

- 빨강: 최우선 예상 주목 영역
- 주황: 높은 예상 주목 영역
- 노랑: 보조 예상 주목 영역
- 숫자: 예상 주목 순서

확률, 체류시간, 실제 사용자 수 또는 측정값처럼 오해될 수 있는 수치를 만들지 않는다.

## 도구가 없을 때

화면 캡처 또는 이미지 편집 기능이 없다면 주목도 맵을 생성했다고 주장하지 않는다. 대신 예상 주목 순서를 텍스트로 설명하고, 시각화에 필요한 스크린샷 업로드나 도구 연결을 안내한다.

## 필수 고지

> 실제 사용자의 시선을 측정한 결과가 아닙니다. 화면의 크기, 대비, 색상, 위치와 정보 위계를 바탕으로 AI가 예측한 주목도입니다.
