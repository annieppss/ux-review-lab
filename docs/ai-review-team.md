# AI 리뷰팀

AI 리뷰팀은 하나의 화면이나 흐름을 서로 다른 역할의 관점에서 검토하는 방식입니다.

## 팀 구성

- 일반 사용성 점검자: 항상 포함
- 사용자가 선택하는 역할: 1~3개
- 종합 정리자: 역할별 의견을 합치고 우선순위를 정리

추천 시작 역할은 다음 세 가지입니다.

1. UX/UI 디자이너
2. 기획자
3. 개발자

역할은 마케터, 특정 연령대 사용자, 접근성 검토자 등으로 자유롭게 교체할 수 있습니다.

## 역할별 관점

### 일반 사용성 점검자

- 처음 봐도 목적을 이해하는가
- 다음 행동을 찾을 수 있는가
- 낯선 용어나 상태가 있는가

### UX/UI 디자이너

- 정보 위계와 시각적 흐름
- CTA와 상태 표현
- 일관성, 접근성, 반응형 위험

### 기획자

- 사용자의 목표와 화면 흐름
- 정책과 예외 상태
- 성공·실패 조건과 다음 단계

### 개발자

- 구현 상태와 데이터 의존성
- 로딩·오류·중복 요청·비동기 상태
- 컴포넌트 및 API 계약의 모호함

## 종합 결과

역할별 의견을 단순히 이어 붙이지 않습니다. 중복되는 문제를 합치고 다음처럼 정리합니다.

- P0: 진행이나 신뢰를 막는 문제
- P1: 사용성 테스트 전에 수정할 문제
- P2: 시각적 완성도 단계에서 다듬을 문제
