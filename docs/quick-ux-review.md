# 빠른 UX 점검

빠른 UX 점검은 전문 디자인 평가보다 처음 화면을 접한 일반 사용자의 이해와 행동에 집중합니다.

## 필요한 정보

- 분석할 화면 또는 프로토타입
- 화면의 목적
- 사용자가 달성해야 할 목표
- 개발 중이거나 동작하지 않는 부분

## 기본 질문

1. 이 화면은 무엇을 하는 화면으로 이해되는가?
2. 가장 먼저 눈에 들어오는 것은 무엇인가?
3. 다음으로 어디를 누를 것 같은가?
4. 이해하기 어렵거나 헷갈리는 부분이 있는가?
5. 오류·로딩·완료 상태에서 다음 행동을 알 수 있는가?

## 권장 결과 형식

```text
한 줄 결론

잘 이해되는 부분
- ...

혼란 가능성이 있는 부분
- ...

우선 수정할 항목
1. ...
2. ...
3. ...

확인이 필요한 실제 사용자 테스트
- ...
```

결과는 실제 사용자 행동 데이터가 아니라 사전 점검 의견임을 항상 표시합니다.
